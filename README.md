# 🌲 Trie In-Memory Database

Цей проєкт — це легка, швидка та інтерактивна консольна In-Memory база даних, побудована на основі структури даних **Префіксне дерево (Trie)**. 

Вона дозволяє створювати множини рядків і виконувати над ними ефективний пошук, включаючи лексикографічне сортування, пошук за діапазоном та складний пошук за шаблоном із використанням символів узагальнення (wildcards).

## 🚀 Як запустити

Для роботи програми потрібен лише встановлений **Python 3.8+**. Жодних додаткових бібліотек встановлювати не потрібно, оскільки проєкт використовує виключно стандартну бібліотеку Python.

1. Завантажте файл з кодом бази даних (наприклад, `trie_db.py`).
2. Відкрийте термінал (або командний рядок).
3. Перейдіть до директорії з файлом та виконайте команду:
   ```bash
   python trie_db.py
   ```
4. Введіть свої команди у консоль. Щоб завершити роботу, натисніть `Ctrl+D` (Linux/Mac) або `Ctrl+Z` та `Enter` (Windows).

## ⚠️ Загальні правила синтаксису

- **Крапка з комою (`;`) обов'язкова!** Кожна команда повинна закінчуватися символом `;`. Усе, що знаходиться після нього на тому ж рядку, вважається коментарем і ігнорується.
- **Регістр:** Ключові слова (`CREATE`, `INSERT`, `SEARCH` тощо) не чутливі до регістру. Імена множин та рядкові значення — **суворо чутливі**.
- **Пробіли:** Будь-яка кількість пробілів між ключовими словами ігнорується.

## 🛠 Довідник команд

### 1. Створення множини
Створює нове порожнє префіксне дерево.
**Синтаксис:** `CREATE set_name;`
**Приклад:** 
```sql
CREATE dictionary;
```

### 2. Додавання слова
Додає новий рядок у вказану множину. Значення повинно бути у подвійних лапках.
**Синтаксис:** `INSERT set_name "value";`
**Приклад:**
```sql
INSERT dictionary "apple";
INSERT dictionary "application";
```

### 3. Перевірка наявності слова
Швидко перевіряє, чи існує точний збіг слова у множині (повертає `TRUE` або `FALSE`).
**Синтаксис:** `CONTAINS set_name "value";`
**Приклад:**
```sql
CONTAINS dictionary "apple";
```

### 4. Візуалізація дерева
Виводить у консоль поточну внутрішню структуру префіксного дерева у вигляді ієрархії.
**Синтаксис:** `PRINT_TREE set_name;`
**Приклад:**
```sql
PRINT_TREE dictionary;
```

### 5. Пошук (SEARCH)
Найпотужніша команда бази даних. Дозволяє виводити всі слова, сортувати їх та фільтрувати.
**Базовий синтаксис:** `SEARCH set_name [*WHERE query] [*ASC | DESC];`

#### Варіанти використання:
* **Вивести всі слова (за замовчуванням за алфавітом):**
  ```sql
  SEARCH dictionary;
  ```
* **Вивести слова у зворотному порядку:**
  ```sql
  SEARCH dictionary DESC;
  ```

#### Фільтрація за допомогою `WHERE`:
Ви можете додати умову фільтрації за допомогою `WHERE BETWEEN` або `WHERE MATCH`.

* **`BETWEEN "from", "to"`** — повертає слова, які знаходяться в лексикографічному діапазоні між `"from"` та `"to"`.
  ```sql
  SEARCH dictionary WHERE BETWEEN "a", "b";
  ```
  
* **`MATCH "pattern"`** — пошук за шаблоном:
  * `?` — замінює рівно **один** будь-який символ.
  * `*` — замінює **будь-яку кількість** будь-яких символів (може бути лише в кінці шаблону).
  
  ```sql
  -- Знайде "cat", "bat", "mat" тощо:
  SEARCH dictionary WHERE MATCH "?at";
  
  -- Знайде "apple", "apply", "application":
  SEARCH dictionary WHERE MATCH "app*";
  ```

Можна комбінувати пошук із сортуванням:
```sql
SEARCH dictionary WHERE MATCH "app*" DESC;
```

## 📝 Приклад повного сеансу
```sql
CREATE animals;
INSERT animals "cat";
INSERT animals "camel";
INSERT animals "cow";
INSERT animals "dog";

CONTAINS animals "cat";  -- Виведе: TRUE
CONTAINS animals "cam";  -- Виведе: FALSE

SEARCH animals WHERE MATCH "c*";  
-- Виведе: "camel", "cat", "cow"
```
