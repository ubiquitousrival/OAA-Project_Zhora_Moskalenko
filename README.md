# Програмна реалізація In-Memory бази даних на основі префіксного дерева (Trie)

## Анотація
Даний проєкт являє собою консольний застосунок, розроблений у рамках лабораторного практикуму з дисципліни «Основи аналізу алгоритмів» (Варіант №14). Програма реалізує механізм управління колекціями рядків в оперативній пам'яті (in-memory) з використанням структури даних класичного префіксного дерева (Trie). 

Програмне забезпечення забезпечує можливість створення множин, вставки даних, виконання перевірки на входження, візуалізації структури дерева, а також здійснення комплексного пошуку із застосуванням лексикографічного фільтрування та регулярних виразів (шаблонів).

## Вимоги до середовища та запуск
Програма розроблена з використанням стандартної бібліотеки мови програмування Python і не потребує встановлення сторонніх залежностей.

* **Мінімальна версія інтерпретатора:** Python 3.8
* **Запуск програми:** 
  Для ініціалізації консольного інтерфейсу необхідно виконати наступну команду в терміналі:
  ```bash
  python trie_db.py
  ```
* **Завершення роботи:** 
  Робота програми припиняється шляхом передачі сигналу EOF (End of File). У більшості терміналів це досягається комбінацією клавіш `Ctrl+D` (для UNIX-подібних систем) або `Ctrl+Z` з подальшим натисканням `Enter` (для ОС Windows).

## Специфікація синтаксису
Командний інтерпретатор застосунку базується на наступних синтаксичних правилах:

1. **Термінатор команди:** Кожна команда в обов'язковому порядку має завершуватися символом крапки з комою (`;`). Будь-які символи, розташовані після термінатора на поточному рядку, ігноруються аналізатором.
2. **Чутливість до регістру:** 
   * Ключові слова команд (`CREATE`, `INSERT`, `SEARCH`, `WHERE`, `MATCH`, `BETWEEN`, `ASC`, `DESC` тощо) не є чутливими до регістру.
   * Ідентифікатори (назви множин) та рядкові літерали (значення) є суворо чутливими до регістру.
3. **Обробка пробілів:** Пробільні символи між лексемами ігноруються і не впливають на виконання команди (за винятком пробілів усередині рядкових літералів, обмежених подвійними лапками).

## Довідник підтримуваних команд

### 1. Створення множини (CREATE)
Ініціалізує нову порожню структуру префіксного дерева із заданим ідентифікатором.
* **Синтаксис:** `CREATE set_name;`
* **Приклад:**
  ```sql
  CREATE dictionary;
  ```

### 2. Додавання елемента (INSERT)
Виконує вставку нового рядкового значення до вказаної множини. Рядковий літерал повинен бути обмежений символами подвійних лапок `""`.
* **Синтаксис:** `INSERT set_name "value";`
* **Приклад:**
  ```sql
  INSERT dictionary "algorithm";
  ```

### 3. Перевірка входження (CONTAINS)
Здійснює перевірку наявності точного збігу заданого рядка у вказаній множині. Повертає булеве значення `TRUE` або `FALSE`.
* **Синтаксис:** `CONTAINS set_name "value";`
* **Приклад:**
  ```sql
  CONTAINS dictionary "algorithm";
  ```

### 4. Візуалізація структури (PRINT_TREE)
Виконує обхід дерева та виводить його внутрішню ієрархічну структуру в консоль зі збереженням відступів для відображення рівнів вкладеності вузлів.
* **Синтаксис:** `PRINT_TREE set_name;`
* **Приклад:**
  ```sql
  PRINT_TREE dictionary;
  ```

### 5. Пошук та фільтрація (SEARCH)
Виконує пошук та вибірку рядків із множини. Команда підтримує необов'язкові блоки для фільтрації результатів (`WHERE`) та напрямку лексикографічного сортування (`ASC` / `DESC`). За замовчуванням результати виводяться в прямому (ASC) порядку.
* **Базовий синтаксис:** `SEARCH set_name [*WHERE query] [*ASC | DESC];`

**Типи запитів (query):**

* **Діапазонний пошук (BETWEEN):** Вибірка рядків, які лексикографічно знаходяться у межах заданого інтервалу (включно).
  * **Синтаксис:** `BETWEEN "from", "to"`
  * **Приклад:**
    ```sql
    SEARCH dictionary WHERE BETWEEN "a", "c" DESC;
    ```

* **Пошук за шаблоном (MATCH):** Вибірка рядків, що задовольняють умови спеціального шаблону.
  * `?` — відповідає рівно одному довільному символу на будь-якій позиції.
  * `*` — відповідає довільній кількості довільних символів (включаючи нуль). Може використовуватись виключно як останній символ шаблону (префіксний пошук).
  * **Синтаксис:** `MATCH "pattern"`
  * **Приклади:**
    ```sql
    -- Знаходження слів, що починаються на "alg":
    SEARCH dictionary WHERE MATCH "alg*";
    
    -- Знаходження слів довжиною 4 символи, що закінчуються на "ode":
    SEARCH dictionary WHERE MATCH "?ode";
    ```

## Типовий сценарій експлуатації
Нижче наведено приклад коректної послідовності команд для перевірки базового функціоналу системи:

```sql
CREATE tokens;
INSERT tokens "cat";
INSERT tokens "camel";
INSERT tokens "cart";
INSERT tokens "dog";

CONTAINS tokens "cat";
-- Очікуваний результат: TRUE

SEARCH tokens WHERE MATCH "ca*";
-- Очікуваний результат: "camel", "cart", "cat"

SEARCH tokens WHERE BETWEEN "camel", "dog" DESC;
-- Очікуваний результат: "dog", "cat", "cart", "camel"
```
